# AI 開發筆記

本檔記錄 AI 輔助開發過程中發現或產生、從原始碼看不出來的實作知識。

目的是讓正式原始碼專注在實作本身，同時保留 AI 輔助開發時容易遺失的工程背景。

## 規則

* 筆記一律使用繁體中文撰寫；程式碼識別名稱（檔案、命名空間、類別、函式、RPC/指令名稱）保留原文。
* 不記錄瑣碎或一看就懂的程式行為。
* 不重複原始碼本身已經很清楚的資訊。
* 保留既有的人工原始碼註解。
* 本檔用來記錄非顯而易見的實作細節、限制、協定假設、設計決策與工程背景。
* `行號` 僅供參考，不可當作穩定的識別依據。
* 同一個問題已有筆記時，更新既有筆記，不要建立重複的筆記。
* 筆記應描述事實、限制或實作理由，而不是泛泛的 AI 說明。
* 安全關鍵或硬體關鍵的警告，必要時可以直接留在原始碼中。
* 開發者明確要求在原始碼加註解時，照開發者的要求做，即使該註解通常應該放在本檔。

## 維護準則

修改原始碼時：

1. 檢查是否有既有筆記受到影響。
2. 實作限制有變動時，更新既有筆記。
3. 只有在資訊有用且不明顯時才新增筆記。
4. 不要記錄 AI 的暫時推理過程或對話式說明。
5. 不要記錄直接讀原始碼就能理解的實作細節。
6. 不要以行號作為辨識程式碼的主要方式，應搭配檔案、命名空間、類別、函式與說明一起判斷。
