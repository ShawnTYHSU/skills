## 指令

對 AI 說：

> 重構 `MoveTo`，保留既有的公尺轉毫米換算。

## 預期行為

AI 應該辨識出這項協定要求已經有記錄。

不應再建立一筆相同的筆記。

若實作有變動，可以更新既有筆記，但要避免不必要的重複。

## 通過條件

* 沒有建立重複的 `MoveTo` 協定筆記。
* 既有文件仍然正確。
* 若實作變動影響到這項限制，是更新既有筆記，而不是新增重複筆記。
