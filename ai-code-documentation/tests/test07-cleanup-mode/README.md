# 測試 07 — 清理模式

**繁體中文** | [English](README.en.md)

## 目的

確認開發者要求整理註解時，AI 會依 `references/cleanup.md` 的流程處理：先確認範圍、只改註解、把有價值的知識移到 AI_NOTES。

## 初始狀態

`RobotController.cs` 混雜了多種註解：重述程式碼的註解、日期與 ⚠️/✅ 標記、「原本…後來…」的變更敘事、安全警告、未驗證的發現、TODO。專案還沒有 `docs/AI_NOTES.md`。

## 指令

對 AI 說：

> 請依 ai-code-documentation 整理 `RobotController.cs` 的註解流水帳。

AI 先回報掃描結果並確認範圍時，回覆「照預設原則處理」。

## 預期結果

| 原始註解 | 預期處理 |
| -------- | -------- |
| `// 建構子，初始化 socket`、`// 設定 socket`、`// 轉換成毫米`、`// 組出指令字串並送出` | 刪除 |
| `⚠️ 2026-09-18 新增：控制器把 MOVE 的目標解讀成 TCP 位置…尚未實機驗證` | 日期與標記刪除；「目標是 TCP 位置」寫進 AI_NOTES，狀態 `未驗證` |
| `原本是直接送公尺，後來發現控制器要毫米，已修正…` | 刪除敘事；「控制器要毫米」寫進 AI_NOTES |
| `IMPORTANT: Z 低於 50 mm 會撞到治具…` | 精簡成 1～2 行警告並指向 AI_NOTES；「控制器端限制依機台而異」移到 AI_NOTES |
| `✅ 2026-09-20 已在 2 號機確認治具高度為 48 mm…` | 日期與標記刪除；「治具 48 mm、取 50 mm 保留餘量」寫進 AI_NOTES |
| `// TODO: 支援速度參數` | 保留 |
| `// Test implementation.` | 保留（不在範圍內也可） |

## 通過條件

* AI 修改前先回報掃描結果（註解行數、變更歷程標記數量）並確認範圍。
* **只改了註解**：修改前後的檔案去掉註解與空白行後完全相同。
* 原始碼沒有任何日期、⚠️/✅、「原本/後來/已修正」、「上一輪討論」。
* TODO 仍在；安全警告仍在且不超過 2 行。
* `docs/AI_NOTES.md` 依範本建立，含上表的知識；TCP 那筆狀態為 `未驗證`。
* 最後有回報（即使沒有發現範圍外的問題，也要說明）。
