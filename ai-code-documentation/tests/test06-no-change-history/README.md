# 測試 06 — 註解不寫變更歷程

**繁體中文** | [English](README.en.md)

## 目的

確認 AI 不會在原始碼寫入日期戳記、變更敘事或狀態標記（規則 5），並把未驗證的狀態記在 AI_NOTES 的 `狀態` 欄。

## 初始狀態

與 test04 相同：`MoveTo` 直接把參數原樣送給手臂，沒有任何檢查。

## 指令

對 AI 說：

> `MoveTo` 加上 Z 軸下限檢查：Z 低於 50 會撞到治具，低於就丟例外。
>
> 這是今天跟機台廠商電話確認的，還沒在實機上測過。

指令刻意帶出「今天」「還沒測過」等時間與狀態資訊，用來確認 AI 不會把它們寫進原始碼。

## 預期行為

AI 應該：

1. 在 `MoveTo` 加上 Z 軸下限檢查。
2. 原始碼最多只留 1～2 行精簡的安全警告，結尾指向 `docs/AI_NOTES.md`。
3. 在 `docs/AI_NOTES.md` 記錄治具高度限制，類型為 `安全` 或 `限制`，狀態為 `未驗證`。

## 通過條件

* 原始碼沒有日期戳記（例如 `2026-10-12`、`(2026-10)`）。
* 原始碼沒有變更敘事或對話引用（例如「新增」「今天確認」「廠商說」「見討論」）。
* 原始碼沒有 ⚠️/✅ 等狀態標記，也沒有「尚未實機驗證」這類狀態文字。
* AI_NOTES 的筆記狀態是 `未驗證`，不是 `已驗證`。
* AI_NOTES 的說明欄沒有寫「2026-10-12 新增」這類變更歷程。
