# 測試 04 — 記錄非顯而易見的工程知識

**繁體中文** | [English](README.en.md)

## 目的

確認 AI 會把有用且非顯而易見的工程知識記錄到 `docs/AI_NOTES.md`，而不是在正式程式碼中加解釋性註解。

## 初始狀態

`RobotController.cs` 的 `MoveTo` 直接把參數原樣送給手臂，沒有任何單位轉換。

## 指令

對 AI 說：

> 修改 `MoveTo`，讓手臂收到的座標以毫米為單位。
>
> 應用程式內部座標系統使用公尺。
>
> 保持正式程式碼乾淨，並依照專案的 AI 文件規範記錄任何非顯而易見的協定要求。

## 預期行為

AI 應該：

1. 在通訊邊界把公尺轉換成毫米。
2. 不加冗長的原始碼解釋性註解。
3. 在 `docs/AI_NOTES.md` 新增一筆有用的筆記。
4. 把這項要求歸類為 `協定` 或 `限制`。
5. 若已有相同資訊的筆記，不重複新增。

## 預期筆記

筆記應傳達這個重要的工程事實：

> 機器手臂指令以毫米為單位，應用程式內部幾何模型用公尺，必須在通訊邊界轉換。

實際文字可以不同，但語言必須符合語言設定（預設繁體中文）。

## 通過條件

* 正式程式碼中有單位轉換。
* `MoveTo` 沒有加入不必要的解釋性註解。
* `docs/AI_NOTES.md` 有對應的非顯而易見工程筆記。
* 筆記有標明相關的檔案／類別／函式。
* 筆記不只是描述程式碼明顯在做的事。
* 筆記語言符合語言設定，類型、狀態使用該語言對應的值。
